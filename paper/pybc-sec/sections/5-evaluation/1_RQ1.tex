
\subsection{RQ1: Bytecode Prevalence and Transparency}\label{sec:effmeasure}

RQ1 measures how often Python bytecode artifacts appear in PyPI distributions and whether they are transparent to source-level inspection.  We count artifacts containing \texttt{.pyc} files, \texttt{\_\_pycache\_\_} directories, source-less bytecode candidates, and dynamic loading indicators.  Results are reported both per distribution artifact and per bytecode file because one artifact can contain many bytecode files.

The reporting claim for RQ1 should be scoped to the measured PyPI population.  If bytecode appears rarely, the result still matters because it establishes that package distributions can carry executable artifacts outside ordinary source inventories.  If bytecode appears frequently, the result strengthens the case for bytecode-aware package scanning.  In both cases, transparency categories explain whether source-level tools would plausibly observe the executable content.
