\subsection{RQ3: CPython Robustness}\label{sec:RQ3}

RQ3 evaluates how CPython behaves when processing malformed or adversarial bytecode artifacts.  For each CPython version, {\tech} prepares version-matched \texttt{.pyc} seeds from CPython unittest-derived source seeds and runs honggfuzz against the bytecode-processing harness.  Outcomes are grouped into normal processing, Python-level exception, timeout, crash, abort, and other abnormal termination.

The main interpretation is conservative.  A crash or abort is a robustness finding that requires triage; it is not automatically an exploitable vulnerability.  RQ3 is reported separately from RQ4 so that bytecode-level runtime behavior is not confused with source-level reachability.
