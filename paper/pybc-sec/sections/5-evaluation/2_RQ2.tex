
\subsection{RQ2: Source Visibility}\label{sec:RQ2}

RQ2 asks whether bytecode artifacts have corresponding source and whether the source matches the bytecode.  We classify each artifact as source-present and matching, source-present but mismatched, source-missing, dynamically generated or loaded, bundled or packed, decompilation-resistant, or unknown.  A source-present artifact is considered matching only when compiling the candidate source under the expected Python version yields equivalent bytecode under the comparison policy.

The key result for this question is the portion of executable bytecode not fully visible through source inspection.  Source mismatch is especially important because source-level scanners may analyze a nearby file while the runtime consumes different behavior from bytecode.
